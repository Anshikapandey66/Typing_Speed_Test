# ⌨️ Typing Speed Test

A simple and interactive Typing Speed Test built using HTML, CSS, and JavaScript.

## 🚀 Features

- 60-second typing test
- Calculate Words Per Minute (WPM)
- Calculate typing accuracy
- Real-time statistics
- Restart test option
- Responsive design
- Clean and simple UI

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript

## 📂 Project Structure

typing-speed-test/
│
├── index.html
├── style.css
├── script.js
└── README.md

## 🎯 How to Use

1. Open `index.html` in your browser.
2. Click on **Start Test**.
3. Start typing the given paragraph.
4. Your WPM and accuracy will be calculated automatically.
5. After 60 seconds, your final result will be displayed.
